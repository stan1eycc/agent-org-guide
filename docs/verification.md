# Verification contract

## Executed offline scope

The candidate auditor inventories every working-tree file without following symlinks, including ignored and hidden paths, checks extended attributes, inventories Git paths before opening content and refuses blocked or reachable unbound blobs; unreferenced unbound local objects are inventoried without reading and are excluded from an explicit ref push and rejects opaque publication payloads, checks local Markdown links, and reports privacy findings by category and relative location only. It does not claim complete secret detection.

The example checker reads only the three synthetic configuration fragments and team manifest. It materializes byte-identical copies in a fresh directory below the operator-selected temporary root, evaluates the proposed admission contract and checks results. It neither imports Hermes nor runs a gateway. The temporary copy is removed by the test itself; only synthetic example artifacts are copied. A clean temporary directory is artifact isolation, not OS sandboxing.

```sh
python3 -B scripts/audit_candidate.py
python3 -B scripts/check_collaboration.py
```
